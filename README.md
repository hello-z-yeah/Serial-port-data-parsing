# 串口数据解析 - 使用说明书

---

## 一、简介

**串口数据解析** 是一款协议数据解析工具，可以根据不同产品的功能协议，自动解析串口通信数据的含义。

### 主要功能

- **粘贴解析**：将 Hex 数据粘贴到输入框，一键解析出指令含义
- **串口实时监控**：连接串口设备，实时采集并解析通信数据
- **导入 Word 协议文档**：将产品的 Word 格式协议文档自动转换为 JSON 配置
- **多产品支持**：通过下拉框切换不同产品的协议，解析对应数据
- **日志保存**：将解析结果保存为日志文件，方便回溯分析

### 支持的协议格式

- 帧头标识（如 `0xA5A5`）
- 命令字识别
- 校验和验证（支持 sum、xor、crc8、crc16_modbus 等）
- 属性块解析（typeid + attrid + value 循环结构）
- 请求/响应方向自动识别

## 二、快速开始

### 方式一：直接使用 exe（推荐，无需安装任何东西）

1. 从 GitHub 仓库下载或克隆项目
2. 双击 `串口数据解析.exe`
3. 首次运行会自动在同目录创建 `product/` 文件夹，并复制默认协议
4. 选择产品协议，开始使用

> **注意**：exe 文件约 19MB，仅支持 Windows 64 位系统。首次启动可能需要几秒钟。

### 方式二：Python 环境运行

**前提**：已安装 Python 3.8+（推荐从 [python.org](https://www.python.org/downloads/) 安装官方版本）

1. 双击 `启动程序.bat`
   - 首次运行会自动安装所需依赖（pyserial、python-docx）
   - 如果有网络问题，会尝试从本地 `packages/` 目录离线安装
2. 程序自动启动

或者手动操作：

```bash
# 安装依赖
pip install -r requirements.txt

# 启动程序
python exe_entry.py
```

## 三、界面功能详解

程序启动后显示主界面，分为以下几个区域：

### 3.1 顶部工具栏

| 按钮/控件 | 功能说明 |
|-----------|---------|
| **产品协议** 下拉框 | 选择当前要解析的产品协议。首次运行默认加载 `v3_serial`（串口接入标准协议V3.0） |
| **刷新** | 重新扫描 `product/` 目录，刷新协议列表（新增协议后使用） |
| **导入Word协议** | 选择 Word 文档（.docx），自动提取协议信息并生成 JSON 配置 |
| **查看协议** | 查看当前选中产品的协议详情（帧结构、命令列表、属性表） |
| **粘贴解析 / 串口实时** | 切换工作模式 |
| **保存日志** | 将解析结果保存到日志文件 |
| **清空** | 清空当前输出区域 |

### 3.2 粘贴解析模式

适用于已有 Hex 数据，需要手动解析的场景。

**操作步骤**：

1. 在顶部下拉框选择产品协议
2. 在输入框中输入 Hex 数据，支持以下格式：
   - 空格分隔：`A5 A5 03 24 00 00 71`
   - 逗号分隔：`A5,A5,03,24,00,00,71`
   - 连续写入：`A5A50324000071`
   - 带 0x 前缀：`0xA5 0xA5 0x03 0x24 0x00 0x00 0x71`
3. 可以一次输入多行，每行一条指令
4. 以 `#` 开头的行为注释，不会解析
5. 选择方向：`auto`（自动识别）、`request`（主机→设备）、`response`（设备→主机）
6. 点击 **解析** 按钮或按 **Ctrl+Enter** 执行解析

**解析结果说明**：

```
━━━ 14:30:25 ━━━
原始: A5 A5 03 24 00 00 71
命令: 0x24  查询属性  [request]
校验: 通过
  · 帧头                      0xA5A5
  · 版本                      0x03
  · 命令字                    0x24 查询属性
  · 数据长度                  0
```

- **校验: 通过** — 数据完整，校验和正确
- **校验: 失败** — 数据可能被篡改或传输错误
- **长度: 不一致** — 协议中定义的长度与实际数据不匹配

### 3.3 串口实时监控模式

适用于连接实际设备，实时查看通信数据的场景。

**操作步骤**：

1. 在顶部下拉框选择产品协议
2. 切换到 **串口实时** 标签页
3. 点击 **刷新** 按钮扫描可用串口
4. 在 **串口** 下拉框选择目标串口（如 `COM3`）
5. 选择 **波特率**（默认 115200，常用值：9600、19200、38400、57600、115200）
6. 点击 **开始监控**，程序开始实时采集数据
7. 点击 **停止监控** 结束采集

**显示选项**：

| 选项 | 说明 |
|------|------|
| **详细模式** | 勾选后显示每个字段的详细解析结果；不勾选则只显示一行摘要 |
| **自动滚动** | 勾选后自动滚动到最新数据；取消勾选可手动查看历史数据 |

**实时数据格式**：

- 紧凑模式：`[14:30:25.123] OK ✓ 0x24   查询属性 [request]  | A5 A5 03 24 00 00 71`
- 详细模式：显示命令名、原始数据、每个字段的详细解析

**状态栏**：

底部状态栏右侧显示实时统计：`帧 42  错误 1  缓冲 3B`
- **帧**：已成功解析的帧数
- **错误**：校验失败或解析错误的帧数
- **缓冲**：当前缓冲区中未组成完整帧的字节数

## 四、导入产品协议

### 4.1 从 Word 文档导入

支持将产品的功能协议文档（.docx 格式）自动解析为 JSON 配置。

**操作步骤**：

1. 点击顶部 **导入Word协议** 按钮
2. 在文件选择对话框中选择 Word 文档
3. 输入产品名称（用作 JSON 文件名，留空则自动从文档识别）
4. 等待导入完成，程序会显示导入结果摘要：
   - 识别的命令数量
   - 识别的属性数量
   - JSON 文件保存路径
5. 导入成功后会自动选择该产品，可直接开始解析数据

**支持的文档格式**：

Word 文档中需要包含以下信息才能正确识别：

- 帧结构表（包含帧头、版本、命令字、数据长度、校验等字段定义）
- 命令字表（包含命令字编号和名称的对照表）
- 属性表（包含属性ID、名称、类型等信息）

**导入结果说明**：

- 导入的协议保存在 `product/` 文件夹中，文件名为产品名称.json
- 导入后可通过 **查看协议** 按钮确认识别是否完整
- 如果识别不全，可以手动编辑 JSON 文件补充信息

### 4.2 手动添加协议

也可以直接创建 JSON 文件放到 `product/` 目录下，程序会自动识别。

**JSON 文件基本结构**：

```json
{
  "product": "产品名称",
  "description": "产品说明",
  "version": "1.0",
  "frame": {
    "header": "0xA5A5",
    "header_size": 2,
    "cmd_offset": 3,
    "length_offset": 4,
    "length_size": 2,
    "checksum": {
      "algorithm": "sum",
      "length": 1
    }
  },
  "commands": [
    {
      "cmd_code": "0x24",
      "name": "查询属性",
      "request": { "format": "attr_query", "name": "查询请求" },
      "response": { "format": "attr_report", "name": "查询响应" }
    }
  ],
  "attributes": {
    "1": { "name": "高度", "typeid": 1, "access": "rw", "unit": "mm" }
  }
}
```

可以参考 `product/` 目录下的 `_template.json` 模板文件。

## 六、命令行模式（高级用户）

除了 GUI 界面，程序也支持命令行操作。

**前提**：已安装 Python 环境和依赖。

### 6.1 查看可用协议

```bash
python -m protocol_parser protocols
```

### 6.2 查看协议详情

```bash
python -m protocol_parser show --product v3_serial
```

### 6.3 解析单条指令

```bash
python -m protocol_parser parse --product v3_serial --hex "A5 A5 03 24 00 00 71"
```

以 JSON 格式输出：

```bash
python -m protocol_parser parse --product v3_serial --hex "A5 A5 03 24 00 00 71" --json
```

### 6.4 批量解析文件

准备一个文本文件，每行一条 Hex 数据：

```text
# 查询属性
A5 A5 03 24 00 00 71
# 设置高度
A5 A5 03 26 04 00 01 01 F4 9A
```

执行批量解析：

```bash
python -m protocol_parser batch --product v3_serial --file data.txt
```

将结果保存为 JSON 文件：

```bash
python -m protocol_parser batch --product v3_serial --file data.txt --out result.json
```

### 6.5 串口实时监控

```bash
# 查看可用串口
python -m protocol_parser ports

# 开始监控
python -m protocol_parser serial --product v3_serial --port COM3

# 指定波特率和详细模式
python -m protocol_parser serial --product v3_serial --port COM3 --baudrate 115200 --detail

# 保存日志
python -m protocol_parser serial --product v3_serial --port COM3 --log monitor.log
```

### 6.6 粘贴交互模式

```bash
python -m protocol_parser paste --product v3_serial
```

进入交互模式后，逐行粘贴 Hex 数据，按回车立即解析。

## 八、常见问题

### Q1：双击 exe 没有反应？

- 首次启动需要几秒钟加载时间，请耐心等待
- 检查是否有杀毒软件拦截，如有请添加信任
- 右键 exe → 属性，检查是否有"安全锁定"提示，如有请点击"解锁"

### Q2：导入 Word 文档后识别的命令/属性不全？

- Word 文档的表格格式需要规范（表头明确、无合并单元格）
- 导入后可以手动编辑 `product/` 目录下的 JSON 文件补充信息
- 也可以点击 **查看协议** 确认识别结果

### Q3：串口连接失败？

- 确认设备已连接且驱动已安装
- 检查串口号是否正确（在设备管理器中查看）
- 检查波特率是否与设备匹配
- 确认串口没有被其他程序占用

### Q4：解析结果显示"校验失败"？

- 数据可能在传输中出错，尝试重新采集
- 检查 Hex 数据是否完整（不要遗漏或多余字节）
- 确认选择的产品协议是否正确

### Q5：如何添加新的产品协议？

- **方式一**：点击 **导入Word协议** 按钮，选择产品的 Word 协议文档自动导入
- **方式二**：手动创建 JSON 文件放到 `product/` 目录下，参考 `_template.json` 模板

### Q6：如何重新打包 exe？

1. 安装官方 Python（需带 tkinter，从 python.org 下载）
2. 双击 `打包exe.bat`
3. 打包完成后，exe 文件在 `dist/` 目录下
4. 将 exe 复制到项目根目录即可

## 九、协议 JSON 配置参考

### 帧结构（frame）

| 字段 | 类型 | 说明 |
|------|------|------|
| `header` | 字符串 | 帧头标识，如 `"0xA5A5"` |
| `header_size` | 整数 | 帧头字节数 |
| `ver` | 字符串 | 版本号，如 `"0x03"` |
| `ver_offset` | 整数 | 版本字段在帧中的偏移量 |
| `ver_size` | 整数 | 版本字段字节数 |
| `cmd_offset` | 整数 | 命令字偏移量 |
| `length_offset` | 整数 | 数据长度字段偏移量 |
| `length_size` | 整数 | 数据长度字段字节数 |
| `length_byte_order` | 字符串 | 长度字节序：`"big"` 或 `"little"` |

### 校验（checksum）

| 字段 | 类型 | 说明 |
|------|------|------|
| `algorithm` | 字符串 | 校验算法：`sum`、`xor`、`crc8`、`crc16_modbus` |
| `length` | 整数 | 校验值字节数 |
| `covers` | 字符串 | 校验覆盖范围 |

### 命令（commands）

| 字段 | 类型 | 说明 |
|------|------|------|
| `cmd_code` | 字符串 | 命令字，如 `"0x24"` |
| `name` | 字符串 | 命令名称 |
| `description` | 字符串 | 命令描述（可选） |
| `direction` | 字符串 | 方向：`request` 或 `response`（单向命令用） |
| `request` | 对象 | 请求格式（双向命令用） |
| `response` | 对象 | 响应格式（双向命令用） |
| `fields` | 数组 | 字段定义列表 |

### 属性（attributes）

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | 字符串 | 属性名称 |
| `typeid` | 整数 | 类型ID |
| `access` | 字符串 | 访问权限：`r`（只读）、`w`（只写）、`rw`（读写） |
| `unit` | 字符串 | 单位（可选） |
| `range` | 字符串 | 数值范围（可选） |
| `enum` | 对象 | 枚举值映射（可选） |
